
# FormFix – AI Prompts Documentation

This document contains the prompts used to plan, develop and improve the FormFix application with AI assistance.

## 1. Project Planning

"Create an offline photo and signature resizing web application for online application forms using HTML, CSS and JavaScript. Include photo upload, signature upload, cropping, resizing and compression."

## 2. User Interface Design

"Design a modern, responsive interface for a photo and signature resizer. Use separate sections for form presets, photo upload, signature upload and downloads. Use a professional teal, coral and amber colour theme."

## 3. Image Upload and Preview

"Write JavaScript to upload JPG, PNG and WEBP images using file inputs and display their previews using HTML Canvas."

## 4. Form Presets

"Create selectable presets for UPSC, UGC-NET and CSIR-UGC NET, along with custom photo and signature dimensions and file-size settings."

## 5. Photo Cropping

"Implement a photo crop preview with an oval face-position guide, zoom slider and vertical positioning slider using HTML Canvas."

## 6. Image Resizing

"Write JavaScript to crop an uploaded photograph according to selected dimensions and generate a downloadable JPEG image."

## 7. Image Compression

"Implement automatic JPEG quality adjustment using Canvas to reduce an image below a specified maximum file-size limit."

## 8. Signature Processing

"Create a separate signature processing feature that resizes the uploaded signature while maintaining its aspect ratio and compresses it to the configured file-size limit."

## 9. Error Handling

"Improve JavaScript error handling for image uploads, missing files, image processing and compression failures."

## 10. Testing and Debugging

"Help identify JavaScript errors, resolve initialization problems and test photo uploads, signature uploads, crop controls and downloads."

## 11. Documentation

"Generate project documentation explaining the FormFix application, its features, technologies, project structure, offline functionality and limitations."

## Conclusion

AI assistance was used during planning, interface development, JavaScript implementation, debugging, testing and documentation. The final application was tested locally in a web browser.
